1. Вывести данные о товаре в алфавитном порядке.
SELECT Goods
FROM SallerGoods
ORDER BY Goods

2. Вывести посредников, поставляющих товар для фирмы.
SELECT DISTINCT Seller
FROM Seller INNER JOIN SallerGoods
ON Seller.INNSeller = SallerGoods.INNSeller
WHERE Seller.Status = 'посредник'

3. На какую сумму было всего куплено каждого товара фирмой.
SELECT Goods, SUM(CostUnit * Count)
FROM SallerGoods
GROUP BY Goods

4. Определить какой товар был куплен у посредников.
SELECT DISTINCT Goods
FROM SallerGoods INNER JOIN Seller
ON SallerGoods.INNSeller = Seller.INNSeller
WHERE Seller.Status = 'посредник'

5. Написать запрос, который выводит название товара и прибыль, полученную от его продажи.
SELECT SallerGoods.Goods, SUM((ClientGoods.CostUnit - SallerGoods.CostUnit) * ClientGoods.Count)
FROM SallerGoods INNER JOIN ClientGoods
ON SallerGoods.ID = ClientGoods.ID
GROUP BY SallerGoods.Goods

6. Определите какие клиенты не покупали подсолнечное масло.
SELECT Client
FROM Client
WHERE INNClient NOT IN (
    SELECT ClientGoods.INNClient
    FROM ClientGoods INNER JOIN SallerGoods
    ON ClientGoods.ID = SallerGoods.ID
    WHERE SallerGoods.Goods = 'масло подсолнечное'
)

7. Показать код и наименование товара, купленного посредниками.
SELECT DISTINCT SallerGoods.Code, SallerGoods.Goods
FROM SallerGoods INNER JOIN ClientGoods
ON SallerGoods.ID = ClientGoods.ID
INNER JOIN Client
ON ClientGoods.INNClient = Client.INNClient
WHERE Client.Status = 'посредник'

8. Вывести список клиентов и сумму прибыли за каждый товар, полученную от продажи черного перца.
SELECT Client.Client, SallerGoods.Goods, (ClientGoods.CostUnit - SallerGoods.CostUnit) * ClientGoods.Count
FROM ClientGoods INNER JOIN Client
ON ClientGoods.INNClient = Client.INNClient
INNER JOIN SallerGoods
ON ClientGoods.ID = SallerGoods.ID
WHERE SallerGoods.Goods LIKE 'Перец черный%'

9. Выведите список товаров в обратном порядке, если товар куплен у производителя и продан в кафе.
SELECT SallerGoods.Goods
FROM SallerGoods INNER JOIN Seller
ON SallerGoods.INNSeller = Seller.INNSeller
INNER JOIN ClientGoods
ON SallerGoods.ID = ClientGoods.ID
INNER JOIN Client
ON ClientGoods.INNClient = Client.INNClient
WHERE Seller.Status LIKE 'производ%' AND Client.Status = 'кафе'
ORDER BY SallerGoods.Goods DESC
